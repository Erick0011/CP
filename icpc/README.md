# ICPC

## Diferenças em relação ao Codeforces
- Time de 3, **um computador**, 5 horas
- Só conta problema aceito; cada submissão errada soma penalidade de tempo
- Pode levar **notebook impresso** (~25 páginas) → gerado a partir de `templates/`
- Mais algoritmos clássicos e mais variedade de temas (geometria, fluxo, strings)

## Simulados
Prova antiga de regional no **Codeforces Gym**, 5h, um computador.
Um arquivo por simulado em `simulados/AAAA-MM-DD-<prova>.md`:

```markdown
# <Regional / ano> — AAAA-MM-DD
- Resolvidos: 5/12 (A, C, D, F, H) — penalidade: 612
- Quem fez o quê: ...
- Erros: WA em F por overflow; demoramos 1h para ler o problema J
- Upsolving: E (fluxo), G (geometria)
- Lição: ...
```
